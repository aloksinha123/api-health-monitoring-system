# API Health Monitoring System

## Features
- Monitors API health using AWS Lambda
- Stores results in DynamoDB
- Scheduled checks using EventBridge
- REST API using API Gateway
- Live dashboard frontend

## Tech Stack
- AWS Lambda
- DynamoDB
- API Gateway
- EventBridge
- HTML, CSS, JavaScript

## How to Run
1. Start frontend:
   python -m http.server 5500

2. Open:
   http://localhost:5500
